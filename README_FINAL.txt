SUPABASE — DO THIS ONCE
1. Open your existing Supabase project.
2. Open SQL Editor.
3. Run orders_setup.sql once.
   This creates/updates the online Orders system AND Ratings & Reviews tables/policies.
4. Do not delete or turn off the Supabase project.

NETLIFY
1. Extract this ZIP.
2. Upload the extracted folder to Netlify Deploys.
3. Make sure index.html is directly inside the folder you upload (not inside another folder).

ADMIN
https://elorafragrance.netlify.app/admin.html
Log in with the Supabase Auth admin account you already created.

IMPORTANT
- The public browser key in supabase-config.js is a publishable key. Do not add a Supabase service-role/secret key to the website.
- Customers can submit reviews, but only approved reviews are shown publicly.
